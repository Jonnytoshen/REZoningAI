# 01 · 接入并验收代码检查

Status: resolved
Type: task
Blocked by: 无

## 目标

按[规格](../spec.md)为 Web、API 和共享聊天包交付可缓存的 Nx ESLint 任务及 Husky 提交前检查，并记录公开命令和真实 Git 提交的验收结果。

## 验收标准

- 全量及单项目命令使用 Nx 官方默认规则，可报告项目内源码、测试和配置的违规。
- 首次全量检查通过；重复运行可复用缓存，共享配置变化后任务重新执行。
- 真实提交验证工作区代码错误和非法消息分别阻断提交；合规提交成功。
- 冻结安装、现有测试和构建通过。

## Answer

- 在独立 `codex/eslint` worktree 接入 Nx 24.0.6 的推断式 lint：三个项目共享 JS/TS 默认规则和模块边界，Web 叠加 React 默认规则，聊天包包含可构建库默认的依赖检查。修复 7 个存量错误，保留 17 个默认警告；未关闭或降低规则。
- 临时克隆通过冻结安装、单项目和全量检查。违规样例验证共享包 TypeScript、Web React hooks 和 Vite 配置、API 测试文件都会被检查；生成物与独立原型目录不参与检查。
- 重复使用相同输入时，三个 lint 任务全部命中缓存；仅修改共享 ESLint 配置后，三个任务均重新执行。
- 真实 Git 提交验证：未暂存的代码错误和不合规的提交消息分别阻止提交；仅有警告时，合规提交成功。钩子未改写文件或改变暂存内容。
- `pnpm test` 的 4 个测试和 `pnpm build` 均通过。规范审查未发现问题；规格审查指出的两处规则匹配范围已对齐默认生成器并重新验收。
