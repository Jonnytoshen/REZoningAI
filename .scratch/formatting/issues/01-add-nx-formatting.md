# 01 · 接入并验收 Nx 代码格式化

Status: resolved
Type: task
Blocked by: 无

## 目标

按[规格](../spec.md)为 Agent 工作区建立统一的格式化规则、全量命令和提交前检查，交付通过全量检查的存量基线。

## 验收标准

- 冻结安装后，格式检查、ESLint、测试和构建通过。重复写入结果一致。
- 格式检查报告受管文件，写入命令修复这些文件。排除文件在写入前后逐字节一致。
- 真实 Git 提交验证格式检查、ESLint 和 Commitlint 分别能拦截违规。检查保留工作区和暂存区，合规提交成功。
- README 记录命令、范围和钩子行为，实施结果留在独立 worktree 供审查。

## Answer

- Nx 24.0.6 通过根 Prettier 3.6.2 配置提供全量读写命令。单引号和 100 列格式规则已应用于 15 个存量文件。README 已记录范围和提交流程。
- 冻结安装、全量格式检查和重复写入验收通过。临时副本验证 6 个受管文件会被报告并修复，16 个排除样例在格式化后逐字节一致。实际运行 Nx 的 TypeScript 库生成器后，全量格式检查通过。
- 真实 Git 提交验证未暂存的格式问题先于 ESLint 阻止提交，检查保留工作区和暂存区。格式合规的 ESLint 错误以及不合规的提交消息分别被拦截，合规提交成功。
- 全量 ESLint、4 项 API 集成测试和构建通过。9 个重新格式化的 TypeScript 和 TSX 文件在规范化编译输出后与基线一致。
