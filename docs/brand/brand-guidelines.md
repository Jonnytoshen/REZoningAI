# REZoningAI 品牌标识设计规范

版本 v1.0 · 2026-11-20 · 适用于 REZoningAI Web 应用及相关物料

## 1. 品牌与设计理念

REZoningAI 是面向陆上风电和集中式地面光伏项目前期选址的助手。标识采用纯字标方案：不借用风机或光伏板的具象图形，而是让字体本身承载识别。

- **RE**：Renewable Energy（可再生能源），使用强调色亮蓝，是整个标识里最先被看到的部分。
- **Zoning 中的 o**：换成“圆环 + 圆点”。圆环代表选址范围（分区），圆点代表被选中的站址，对应产品的核心功能。
- **AI 标签**：黑色圆角标签，标明这是 AI 驱动的助手。

## 2. 名称书写

- 正确：REZoningAI（连写，RE、Z、AI 大写，其余小写）。
- 错误：Rezoningai、RE Zoning AI、REZONINGAI、rezoningai。
- 正文中提到产品名时使用纯文本 REZoningAI，不需要带标识。

## 4. 色彩

| 名称 | HEX | RGB | 用途 |
| --- | --- | --- | --- |
| 亮蓝 | #3964FE | 57, 100, 254 | “RE”、圆点、强调 |
| 墨黑 | #1B1B1B | 27, 27, 27 | 字标主体、AI 标签、深色背景 |
| 奶白 | #FBF8F3 | 251, 248, 243 | 浅色背景、AI 标签内的文字 |
| 深色底蓝 | #7C9AFF | 124, 154, 255 | 深色背景上代替亮蓝 |
| 辅助灰 | #5A5650 | 90, 86, 80 | 说明语、次要文字 |

**对比度（WCAG 计算值，约数）**

- 亮蓝 / 奶白约为 4.48:1，低于普通正文的 WCAG AA 门槛（4.5:1）。适用于标志和大字号强调，奶白底上的普通正文可使用墨黑或辅助灰。
- 亮蓝 / 墨黑：3.6:1。不用于文字，深色背景改用深色底蓝。
- 深色底蓝 / 墨黑：6.5:1。
- 墨黑 / 奶白：16:1。
- 辅助灰 / 奶白：6.9:1。

**使用原则**：蓝色只用于“RE”和圆点，保持小面积，让它成为视觉重点。

## 5. 字体

- **字标**：Manrope ExtraBold（字重 800），字距约 −3%（字号 88px 时为 −3px）。交付的 SVG 已将字标转为轮廓，不依赖字体安装。
- **中文说明语**：苹方 / 微软雅黑 / 思源黑体（Noto Sans SC），Medium（500）。
- **英文说明语**：Manrope Medium（500），全大写，字距约 0.3em。
- 字标不要用文字重新输入，必须使用提供的矢量文件。

## 6. 构造与比例

以字标字号为基准单位 S。下表同时给出 S = 88 时的参考数值。

| 部位 | 参考值（S = 88） | 相对比例 |
| --- | --- | --- |
| 字距 | −3 | 约 −0.034S |
| 圆环外径 | 50 | 0.57S |
| 圆环线宽 | 12 | 0.14S |
| 圆点直径 | 13 | 0.15S |
| 圆环与相邻字母间距（每侧） | 1 | 约 0.01S |
| 圆环下沿低于基线 | 1 | 约 0.01S（视觉补偿） |
| AI 标签字号 | 40 | 0.45S |
| AI 标签高度 | 54 | 0.61S |
| AI 标签圆角 | 12 | 0.14S |
| AI 标签内边距（上下 / 左右） | 7 / 15 | 0.08S / 0.17S |
| 字标与 AI 标签间距 | 16 | 0.18S |

- 圆环替换 Zoning 中的 o，位于 Z 与 ning 之间。
- AI 标签相对字标行高垂直居中，不与字母基线对齐。
- 整体（不含留白）宽高比约 5.5:1。

## 7. 留白与最小尺寸

- **留白**：Logo 四周不小于圆环外径（0.57S）。导出文件自带的内边距小于该值，不能当作留白。
- **最小尺寸（建议）**：主 Logo、反白版、单色版宽度不小于 120px（印刷不小于 30mm）；符号和应用图标不小于 16px。
- 小于最小尺寸时，改用符号或应用图标。

## 8. 背景与版本选择

| 背景 | 使用版本 |
| --- | --- |
| 奶白、白色、浅灰 | 主 Logo |
| 墨黑、深灰、深蓝灰 | 反白版 |
| 照片、渐变、复杂图案 | 单色版，放在对比足够的区域 |
| 品牌亮蓝背景 | 使用蓝底应用图标，不要把主 Logo 直接放在亮蓝上 |

## 9. 说明语

- 中文：陆上风电 · 地面光伏 · 前期选址助手
- 英文：ONSHORE WIND · UTILITY-SCALE PV · SITING
- 说明语不属于 Logo 本体，单独排版，居中放在 Logo 下方，与 Logo 间距约 0.3S。
- 说明语上方可加一条短横线（亮蓝，40 × 4，S = 88 时）。
- 中文说明语字号约 0.23S，字距 2px；英文说明语字号约 0.14S，字距 3.5px，颜色用辅助灰。

## 10. 应用图标与 favicon

- 画布按 64 单位计：圆角 16（25%）；圆环外径 39（约 61%），线宽 9；圆点直径 10（约 16%）；整体居中。
- 墨黑底：圆环为奶白，圆点为深色底蓝。蓝底：圆环与圆点均为奶白。
- 浏览器标签页、应用内小图标用墨黑底；头像用蓝底。
- 16px 为最小使用尺寸，32px 为推荐的 favicon 尺寸。

## 11. 禁用规范

- 不更改颜色，包括把“RE”改成其他颜色、给圆点换色。
- 不拉伸、压扁、倾斜或旋转。
- 不添加阴影、描边、渐变、发光或立体效果。
- 不拆开、重排，或改变 RE、Zoning、AI 标签之间的相对位置。
- 不移动圆点位置，不改变圆环粗细。
- 不用字体重新输入字标。
- 不把主 Logo 放在对比度不足的背景上。
- 不在深色背景上用亮蓝写文字。

## 12. 开发使用

色彩变量：

```css
:root {
  --rez-blue: #3964FE;
  --rez-ink: #1B1B1B;
  --rez-cream: #FBF8F3;
  --rez-blue-on-dark: #7C9AFF;
  --rez-gray: #5A5650;
}
```

导航栏按实际背景选择标识。浅色背景使用主 Logo，深色背景使用反白版。下方以浅色导航栏为例，`src` 填写部署后的素材 URL。

```html
<img src="REZoningAI-logo-primary.svg" alt="REZoningAI" height="32" />
```
