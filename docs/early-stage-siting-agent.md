# 风光项目前期选址 Agent 方案

本方案于 2026 年 11 月 18 日确认，作为后续实现的基线。

面向中国大陆陆上风电和集中式地面光伏项目的一线开发人员。开发人员提供一个区域线索，Agent 找出值得继续核实的片区，说明每个片区的判断依据、已发现的风险和资料缺口，帮助开发人员决定下一步去哪里查资料或踏勘。

## 首期流程

1. **发起选址。** 开发人员在地图工作台通过对话或圈画指定搜索范围，并给出项目类型。搜索范围可以来自行政区边界或手绘边界，目标装机容量可选填。Agent 在地图上展示本次采用的范围，缺少启动信息时只追问缺项。
2. **准备资料。** 项目团队确认试点适用的排除规则、筛选条件和关键图层。Agent 读取已确认的资料，也可以检索公开资料、提供来源并指出版本冲突或覆盖缺口。变更规则和采信争议资料由开发人员确认。
3. **执行筛选。** 对来源可追溯、规则明确且确认适用的资料，空间工具剔除受约束的重叠区域。剩余范围按团队确认的项目类型筛选条件圈出有正向依据的片区。每片连续区域是一个候选区。已确认的排除带将片区完全隔开时分别列出，仍连通的片区可以带有内部扣除范围。
4. **交付成果。** 地图展示搜索范围、候选区、已执行的排除范围和已知资料缺口。点击候选区，可以查看推荐理由、对应规则或资料、风险和下一步查证事项。资料缺口有已知位置时标出影响范围，边界或覆盖情况尚不明确时说明影响仍待查证。
5. **人工复核与重跑。** 开发人员对当轮候选区记录继续核实或暂缓，并可留备注。补充资料或修改规则后可发起新一轮，仍能回看原有成果和复核意见。

## 资料缺口如何影响结果

有正向依据、可以圈出范围的片区，即使缺少关键图层，也可以作为待补资料的候选区交付，并指出具体缺项。证据不足以圈出候选区时，交付本轮已完成的检查、判断受限的原因和继续所需的资料。口径和资料足以完成筛选且没有找到符合条件的片区时，交付空结果，并说明导致为空的规则或条件。

每份关键资料记录来源、版本、适用范围和已知覆盖缺口。用于排除的图层还需确认使用条件、坐标系及空间边界的适用性。公开文本、图集和资源估算可用于发现资料线索与初筛依据，采用时保留来源和使用口径。

## Agent 与工具的分工

| 组成 | 职责 |
| --- | --- |
| 地图工作台 | 确认搜索范围，查看候选区、风险与资料缺口，记录复核意见，回看历史成果。 |
| Agent | 理解范围与项目类型，调度已确认的资料和规则，补查线索，解释空间工具返回的结果。 |
| 空间工具 | 执行范围裁剪、图层叠加、排除和连通片区识别，返回空间边界和对应判断依据。 |
| 选址记录 | 按轮保留搜索范围、项目类型、当时的规则与条件、资料版本、空间结果、待核实事项和复核意见。 |

同一关键图层更新后，历史成果仍指向当时使用的版本和结果。每条推荐理由或已执行的排除，都可以回查对应规则与资料。

## 试点和验收

选择一个真实县域、一种项目类型。优先选择开发团队能确认关键资料、也能人工复核结果的组合。启动前确认搜索边界、支持推荐的资源或地形资料，以及适用的关键约束图层清单，逐项记录能够使用的资料和已知缺口。风资源、太阳能资源和地形可从公开数据补充初筛依据。试点实际采用的约束边界以当地资料核验结果为准。[Global Wind Atlas 用途说明](https://globalwindatlas.info/en/about/purpose) · [Global Solar Atlas 中国数据](https://www.globalsolaratlas.info/download/china) · [Copernicus DEM 数据说明](https://dataspace.copernicus.eu/explore-data/data-collections/copernicus-contributing-missions/collections-description/COP-DEM)

| 验收场景 | 通过条件 |
| --- | --- |
| 正常筛选 | 已确认的重叠限制被剔除。地图显示候选区，开发人员可以逐条查证推荐理由并保存复核意见。 |
| 部分缺资料 | 成果指出缺少的图层、已知受影响的范围及下一步查证动作，并保留已有依据的候选区。 |
| 无候选区 | 成果明确显示筛选完成但结果为空，或说明资料不足以形成候选区，并给出各自的原因。 |
| 更新资料重跑 | 新一轮体现资料变化。原有的边界、依据和复核意见仍可回看。 |

## 后续业务计算

业务计算按需作为工具接入，也可由 MCP 服务提供工具。每个模型明确输入、单位、假设、版本和输出。Agent 根据相应选址成果准备输入，缺项时向开发人员指出需要补齐的字段。测算记录关联相应的选址轮次和候选区，并保留实际输入、假设和结果。

现有陆上风电工程概算和财务原型可作为后续接入对象。财务测算还需要独立提供净上网电量等经营输入。首期先走通区域筛选、复核与重跑，再按需求逐项增加模型。[工程概算模型](../engineering_estimate/README.md) · [财务模型说明](../finance/WTG1-财务模型说明.md)
